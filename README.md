# ذاكرلي — Zakerly

مساعد مذاكرة ذكي (تطبيق ويب يتثبّت على الموبايل والكمبيوتر — PWA) بالعربي والإنجليزي، وفيه وضع فاتح وداكن.

الطالب يضيف المادة من **PDF** أو **يصوّر بالكاميرا** أو **صور** أو **نص**، ويستخدم مفتاح Claude بتاعه في:
ملخصات (مختصر / مفصّل / نقاط / ليلة الامتحان) · أسئلة متوقعة بإجابات نموذجية · اختبار تفاعلي بالدرجة · بطاقات مراجعة بالتكرار المتباعد · "اشرحلي ببساطة" · المصطلحات · خريطة ذهنية · دردشة مع الدرس · قراءة بصوت · طباعة/PDF.
وكمان: جلسات تركيز (بومودورو)، هدف يومي، أيام متتالية.

**نموذج الربح:** 3 أيام مجاناً، بعدها **اشتراك شهري بـ 20 جنيه** (الدفع عن طريق Paymob). الأدمن بيغيّر السعر وعدد أيام الفترة المجانية من **لوحة التحكم** (`#/owner`).

كل دفعة بتضيف 30 يوم. ولو الطالب جدّد بدري، الشهر الجديد بيتحسب بعد اللي فاضل له، فمش بيخسر أيام. قبل نهاية الاشتراك بـ 5 أيام بيظهرله تنبيه يجدّد. (التجديد يدوي، يعني مفيش خصم تلقائي من الكارت.)

**الـ AI في التطبيق:**
- **مجاني (جاهز) — الافتراضي:** التطبيق بيفتح على **Gemini** على طول من غير ما الطالب يحط أي مفتاح. الطلبات بتعدّي على سيرفرك (`ai-proxy`) وبتستخدم **مفتاحك إنت**، ولكل طالب **25 طلب في اليوم** (بتوقيت القاهرة). الأدمن يقدر يغيّر الحد ده من لوحة التحكم.
- **مفتاح الطالب الخاص (من غير حد):** لو الطالب عايز استخدام أكتر، يختار من الإعدادات **Claude** (مفتاح من [console.anthropic.com](https://console.anthropic.com)) أو **Gemini** (مفتاح من [aistudio.google.com](https://aistudio.google.com/apikey)). طلباته في الحالة دي بتروح من جهازه للمزوّد على طول، ومش بتتحسب من حدّه ولا بتكلفك حاجة.

اشتراك Gemini بتاع الجامعة مش مفتاح API ومينفعش هنا.

---

## التشغيل محلياً

```bash
npm install
npm run dev
```

من غير إعداد Supabase التطبيق بيشتغل مجاني بالكامل (مفيد للتجربة). عشان تفعّل الحسابات والدفع اعمل الخطوات اللي تحت وحط القيم في `.env` (شوف `.env.example`).

## الإعداد الكامل (مرة واحدة)

### 1) Supabase (الحسابات + الاشتراكات + السعر)

1. اعمل مشروع مجاني على [supabase.com](https://supabase.com).
2. من **SQL Editor** شغّل محتوى الملف `supabase/migrations/0001_billing.sql`.
3. **Authentication → Providers → Email**: خليه مفعّل.
4. **Authentication → Email Templates → Magic Link**: حط الكود في الرسالة، مثلاً:
   ```html
   <h2>كود الدخول لذاكرلي</h2>
   <p style="font-size:28px;letter-spacing:6px"><b>{{ .Token }}</b></p>
   ```
   (الطالب بيدخل بكود 6 أرقام بيوصله على الإيميل، من غير باسورد.)
5. من **Project Settings → API** خد `Project URL` و `anon public key`، وحطهم في `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.

### 2) خلّي نفسك صاحب التطبيق

سجّل دخول في التطبيق بإيميلك مرة، وبعدها شغّل في SQL Editor السطر ده (ممكن تعمل أكتر من أدمن بنفس الطريقة):

```sql
update public.profiles set is_admin = true where email = 'your@email.com';
```

هتلاقي «صفحة صاحب التطبيق» في القائمة وفي الإعدادات. منها بتعمل الآتي:
- تغيّر سعر الاشتراك الشهري (الافتراضي 20 جنيه) وعدد أيام الفترة المجانية. السعر الجديد بيسري على أي دفع جاي.
- تشوف عدد المستخدمين، واللي في الفترة المجانية، والمشتركين حالياً، وإيرادات الشهر وإجمالي الإيرادات.
- تضيف شهر لطالب بنفسك (لو دفعلك كاش أو إنستاباي) أو تلغي اشتراكه.

### 3) Paymob (استقبال الدفع)

1. اعمل حساب تاجر على [paymob.com](https://paymob.com)، وفعّل طرق الدفع اللي عايزها (كروت، محافظ…).
2. من لوحة Paymob خد: **Secret Key** و **Public Key** و **HMAC Secret** و **Integration IDs** لطرق الدفع.
3. ثبّت [Supabase CLI](https://supabase.com/docs/guides/cli) وبعدها:
   ```bash
   supabase login
   supabase link --project-ref <project-ref>
   supabase secrets set \
     PAYMOB_SECRET_KEY=... \
     PAYMOB_PUBLIC_KEY=... \
     PAYMOB_HMAC_SECRET=... \
     PAYMOB_INTEGRATION_IDS=123456,789012 \
     APP_URL=https://<username>.github.io/<repo>
   supabase functions deploy create-payment
   supabase functions deploy paymob-webhook --no-verify-jwt
   supabase functions deploy ai-proxy
   ```
   الـ webhook عنوانه `https://<project-ref>.supabase.co/functions/v1/paymob-webhook`، وبيتبعت لـ Paymob تلقائياً مع كل عملية دفع.
4. **جرّب الأول بوضع الاختبار (Test mode) في Paymob** واتأكد إن الاشتراك بيتفعّل لوحده بعد الدفع وإن تاريخ نهايته اتمدّ 30 يوم، قبل ما تشغّل الحساب الحقيقي.

### 4) الـ AI المجاني (Gemini بمفتاحك)

1. اعمل مفتاح من [Google AI Studio](https://aistudio.google.com/apikey).
2. حطه كـ secret وارفع الدالة:
   ```bash
   supabase secrets set GEMINI_API_KEY=...
   supabase functions deploy ai-proxy
   ```
3. من لوحة التحكم تقدر تغيّر:
   - **حد الطلبات اليومي** لكل طالب (الافتراضي 25).
   - **نموذج Gemini**. لو سبته فاضي، الدالة بتختار أحدث نموذج Flash لوحدها.
   - وكمان بتشوف عدد الطلبات المجانية النهارده، وعدد الطلبة اللي استخدموها.

> **مهم:** الباقة المجانية من جوجل ليها حدود على **مشروعك كله** (عدد طلبات في الدقيقة وفي اليوم)، والحدود دي بتتقسم على كل الطلبة. ومع عدد كبير من الطلبة هتحتاج تفعّل الدفع (Billing) في Google Cloud. كمان جوجل ممكن تستخدم بيانات الباقة المجانية في تحسين منتجاتها، والباقة المدفوعة مش بتعمل كده. لو الطلب فشل من عند جوجل، الطالب بيرجعله طلبه ومش بيتحسب عليه.

### 5) النشر على GitHub Pages

1. في GitHub: **Settings → Pages → Source = GitHub Actions**.
2. **Settings → Secrets and variables → Actions**: ضيف `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`.
3. أي push على `main` بينشر التطبيق تلقائياً (`.github/workflows/deploy.yml`).
   - **من غير secrets بتوع Supabase:** التطبيق بيشتغل من غير حسابات ولا اشتراك، وكل طالب بيحط مفتاح Gemini المجاني بتاعه. أول ما يفتح التطبيق بتظهرله خطوتين بيجيب بيهم المفتاح في أقل من دقيقة. أول ما تضيف secrets بتوع Supabase، النشر الجاي بيشغّل الحسابات والاشتراك والـ AI المجاني الجاهز.
4. الطالب يفتح الرابط ويختار «إضافة إلى الشاشة الرئيسية» / «تثبيت».

## ملاحظات أمان

- السعر بيتقري من قاعدة البيانات على السيرفر وقت الدفع، يعني الطالب ميقدرش يغيّره.
- التفعيل بيحصل بس من الـ webhook بعد التحقق من توقيع Paymob (HMAC)، أو منك من صفحة صاحب التطبيق.
- مدة الفترة المجانية بتتحسب بساعة السيرفر، فتغيير تاريخ الموبايل مش بيمدّها.
- طلبات الـ AI بتروح من جهاز الطالب لـ Anthropic مباشرة بمفتاحه هو. عشان كده القفل بيمنع المستخدم العادي، لكن مبرمج شاطر يقدر نظرياً يعدّل كود الصفحة على جهازه ويعدّي القفل. منع ده تماماً محتاج إن كل طلبات الـ AI تعدّي على سيرفرك.
